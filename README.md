# Azmat Ali — Professional Portfolio

## Files
- `index.html` — portfolio page
- `style.css` — responsive design
- `script.js` — mobile navigation and current year
- `Azmat_Ali_CV.pdf` — add your latest CV PDF here before publishing

## Publish on GitHub Pages
1. Create a new public GitHub repository, for example `azmat-ali-portfolio`.
2. Upload these files and your latest CV PDF.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. Save. GitHub will provide the portfolio URL.

## Important
The portfolio content is based on the supplied Azmat Ali CV. Replace the CV PDF with the latest final version before publishing.
